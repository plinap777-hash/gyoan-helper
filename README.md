# 동료장학 수업지도안 도우미

세종형 「질문·탐구·성찰」 **초등 동료장학 수업지도안**을 단계별로 작성하고 **Word(.docx)** 로 내려받는 웹앱입니다.
서버·회원가입·API 키가 필요 없고, 입력 내용은 사용하는 선생님의 브라우저에만 저장됩니다.

## 지도안 유형
| 유형 | 구성 |
|---|---|
| ① 교과 탐구 독서 | 수업 개요 → 교육과정 분석 → 수업 흐름 → 탐구 설계 → 수업의 실제 → 학생 평가 → 붙임(읽기 자료) |
| ② 교과탐구 인공지능활용 | 개요(인공지능 도구) → 교육과정 분석 → 질문중심 인공지능 활용 수업의 흐름 → AI 활용 설계(윤리·안전 검증) → 수업의 실제 → 학생 평가 → [참고] 참고자료 |

## 주요 기능
- 학년-학기 → 교과 → 단원을 목록에서 선택
- 해당 학년군 **성취기준 목록**에서 골라 넣기 (검색 가능)
- 영역을 고르면 **핵심 아이디어, 내용 요소(지식·이해 / 과정·기능 / 가치·태도)** 목록에서 골라 넣기
- 단계별 작성 요령·예시·자동 점검
- **장학자료 안내 / 단계별 “생각해 보기”**: 화면 위 안내문(취지)과 각 단계 첫머리의 생각해 보기 질문. 내용은 `data/think.js`에서 고칠 수 있습니다.
- 빈 양식 보기 / Word(.docx) 내려받기 / 인쇄·PDF / 작업 저장·불러오기(.json)

## 선생님용 사용법
1. 배포 주소에 접속해 오른쪽 위에서 지도안 유형을 고릅니다.
2. 단계 순서대로 작성합니다. 오른쪽의 작성 요령과 자동 점검을 참고하세요.
3. [전체 미리보기]에서 확인한 뒤 **Word(.docx) 내려받기** → 한글(HWP)에서 열어 다듬습니다.
4. 작성 중간에 [작업 저장(.json)]을 해 두면 다른 컴퓨터에서도 [작업 불러오기]로 이어 쓸 수 있습니다.

## 제출 버튼 설정
`config.js`의 `SUBMIT_URL: ''` 따옴표 안에 지도안을 제출할 구글 공유 드라이브 폴더 링크를 넣으면 화면 위쪽과 내보내기 화면에 **최종 지도안 제출하기** 버튼이 나타납니다. 비워 두면 버튼이 숨겨집니다. 안내 문구는 `SUBMIT_NOTICE`에서 바꿀 수 있습니다.
GitHub에서는 저장소의 `config.js`를 열고 연필(편집) 버튼으로 바로 고칠 수 있습니다.

## GitHub Pages 배포
1. GitHub에서 새 저장소(Public)를 만듭니다. (예: `gyoan-helper`)
2. 저장소 화면의 **Add file → Upload files**에 이 폴더의 파일과 폴더(`data`, `vendor` 포함)를 그대로 끌어다 놓고 **Commit changes**.
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**
4. 1~2분 뒤 `https://<계정이름>.github.io/<저장소이름>/` 으로 접속됩니다. 이 주소를 선생님들께 안내하세요.

로컬 실행: `index.html`을 더블클릭해 브라우저로 열어도 됩니다.

## 파일 구성
```
index.html          화면
config.js           학교 설정(지도안 제출 링크)
style.css           디자인
app.js              앱 동작
data/standards.js   성취기준 592개(교과·학년군·단원 묶음)
data/content.js     내용 체계(영역별 핵심 아이디어·내용 요소)
vendor/docx.js      Word 생성 라이브러리 (docx, MIT License)
.nojekyll           GitHub Pages 설정 파일
```

## 자료 출처와 유의 사항
- 성취기준·내용 체계: 세종특별자치시교육청 고시 제2025-9호 「세종창의적교육과정 초등학교 생각자람교육과정(성취기준).pdf」
- 내용 체계는 원문 표를 옮겨 적은 것이므로 사용 전 원문과 대조를 권장합니다.
- 단원(성취기준 묶음)과 영역의 연결(사회·과학)은 작성자가 판단해 추천하는 값이며, 수업 의도에 맞게 바꿔 쓸 수 있습니다.
- AI가 만든 초안은 반드시 사실과 교육과정 원문을 확인한 뒤 사용하세요.
