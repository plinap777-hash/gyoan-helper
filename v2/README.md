# 수업장학 지도안 도우미 2

세종형 「질문·탐구·성찰」 수업장학(동료장학)용 수업지도안 작성 도우미입니다.

- 지도안 유형: ① 교과 탐구 독서 ② 질문중심 수업
- **AI 프롬프트 생성기**: 수업 주제, 본질·탐구 질문, 과정안, 독서 자료, 질문 초점(QFT), 학생 질문 분류, 활동지, 평가 기준, 성찰 활동, 학생용 AI 카드, 동료장학 협의 질문, 지도안 점검 프롬프트를 입력한 내용으로 자동 생성
- AI로 한 번에 만들기, 단계별 자동 점검, 전체 미리보기, Word(.docx) 내려받기, 작업 저장·불러오기(.json)

## GitHub Pages로 배포하기
1. GitHub에서 새 저장소를 만듭니다(예: `suupjanghak-2`, Public).
2. 이 폴더의 파일을 **모두** 저장소 맨 위에 올립니다. (`index.html`이 맨 위에 있어야 합니다. `.nojekyll`도 함께 올리세요.)
3. 저장소 **Settings → Pages → Branch: main / (root) → Save**.
4. 1~2분 뒤 `https://plinap777-hash.github.io/gyoan-helper/v2/` 주소로 열립니다. 이 주소를 선생님들께 안내하면 됩니다.

## 사용 안내
- 서버 없이 브라우저에서만 동작하며, 입력 내용은 각자의 브라우저에만 자동 저장됩니다.
- 다른 기기로 옮기려면 [작업 저장(.json)] → [작업 불러오기]를 사용하세요.
- 학생 실명·사진 등 개인정보는 입력하지 마세요.
- AI가 만든 초안은 교육과정 원문과 사실을 확인한 뒤 고쳐 쓰세요.

## 파일 구성
- `index.html` 화면 / `app.js` 기능 / `style.css` 디자인
- `data/standards.js` 성취기준, `data/content.js` 내용 체계
- `vendor/docx.js` Word 파일 생성 라이브러리
